# QueueLess — Virtual Queue Simulator

**CMR University | Department of Information Technology**

**Course:** 4CSPL2023 — Object Oriented Programming  
**Assignment:** 2 — Java Mini Application Development

## About
QueueLess is a Java Swing application that simulates a token-based queue system for a service counter.

## Features
- Generate new tokens
- Call the next waiting token
- View waiting tokens
- Reset the queue
- Handle empty-queue situations

## Technologies
- Java
- Java Swing and AWT
- Queue and LinkedList

- `QueueLess.java` — Java source code
- `PROJECT_REPORT.md` — Project report
